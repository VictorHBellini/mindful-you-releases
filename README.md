# Mindful You — Versão 1.0.0

**Primeira versão pública para Android**

O Mindful You é um aplicativo de acompanhamento emocional e organização de registros pessoais.

### Funcionalidades

- Cadastro e acesso à conta.
- Registro de check-ins emocionais.
- Avaliações e consulta de históricos.
- Armazenamento local dos registros pessoais.
- Personalização do tema visual.
- Configurações de conta e privacidade.

### Instalação

1. Baixe o arquivo `MindfulYou-v1.0.0.apk` na seção Assets desta versão.
2. Abra o arquivo no dispositivo Android.
3. Autorize a instalação por essa fonte, caso o Android solicite.
4. Conclua a instalação e abra o Mindful You.

**Requisitos:** Android 7.0 ou superior.

### Privacidade e armazenamento

Os históricos pessoais são mantidos localmente no dispositivo. A desinstalação do aplicativo ou a perda do aparelho pode resultar na perda desses dados.

Consulte a Política de Privacidade antes de utilizar o aplicativo.

### Atualizações

Para preservar os dados locais, instale versões futuras sobre a instalação existente, sem desinstalar o aplicativo.
